# TikTok DM Sender - Chrome 扩展插件

给 TikTok 达人发送私信的 Chrome 浏览器插件。

---

## 安装方法

### 1. 下载插件
将 `tiktok-dm-extension` 文件夹下载到本地。

### 2. 打开 Chrome 扩展页面
- Chrome 地址栏输入：`chrome://extensions/`
- 或者：设置 → 更多工具 → 扩展程序

### 3. 开启开发者模式
- 右上角开启「开发者模式」

### 4. 加载插件
- 点击「加载已解压的扩展程序」
- 选择 `tiktok-dm-extension` 文件夹

---

## 使用方法

### 1. 登录 TikTok
用 Chrome 打开 https://www.tiktok.com 并登录你的账号

### 2. 打开达人主页
找到要发私信的达人主页，点击进入

### 3. 使用插件
- 点击 Chrome 右上角的插件图标（📩）
- 输入私信内容
- 点击「发送私信」

### 4. 等待完成
插件会自动：
1. 找到「消息」按钮并点击
2. 等待消息对话框出现
3. 填写私信内容
4. 点击发送

---

## 注意事项

- **不要发太快**：建议每条间隔 30 秒以上，避免被 TikTok 风控
- **内容要真实**：避免频繁发送相同内容
- **先测试**：先用一条私信测试是否正常

## 常见问题

**Q: 点击插件没反应**
A: 确保在 TikTok 达人主页上使用，不是首页或搜索页

**Q: 显示"未找到消息按钮"**
A: TikTok 页面结构可能变了，刷新页面重试

**Q: 发送失败**
A: 检查账号是否已登录，或者达人是否开启了私信限制
